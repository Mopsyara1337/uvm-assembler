# Ассемблер и интерпретатор УВМ

Практическое задание №3 по дисциплине
«Конфигурационное управление».

Вариант №13.

## Общее описание

Проект представляет собой ассемблер и интерпретатор
учебной виртуальной машины.

Ассемблер преобразует исходную программу в формате JSON
в промежуточное представление, а затем формирует машинный
код и сохраняет его в бинарный файл.

Интерпретатор загружает машинный код в объединённую
память команд и данных, декодирует и последовательно
выполняет инструкции учебной виртуальной машины.

После выполнения программы содержимое указанного
диапазона памяти сохраняется в CSV-файл.

Язык реализации — Python.

## Архитектура УВМ

- 128 регистров общего назначения.
- Объединённая память команд и данных.
- 29-битная адресация памяти.
- Счётчик команд (Program Counter).
- Размер машинной команды — 6 байт.
- Порядок байтов — Little-endian.

Память реализована на основе словаря.
Ключом является адрес ячейки, значением — её содержимое.
Неинициализированные ячейки содержат ноль.

В одной ячейке памяти хранится целое число.
Одна машинная команда занимает одну ячейку.

Выполнение программы осуществляется по циклу
Fetch — Decode — Execute.

## Спецификация УВМ

Размер каждой машинной команды составляет 6 байт.
Количество регистров — 128.

| Команда | Код операции | Назначение |
|---|---:|---|
| LOAD_CONST | 59 | Загрузка константы |
| READ | 60 | Чтение из памяти |
| WRITE | 43 | Запись в память |
| ADD | 30 | Сложение |

## Синтаксис языка ассемблера

Исходная программа представляет собой JSON-массив объектов.
Каждый объект содержит название операции и её операнды.

### LOAD_CONST

- register — номер регистра (7 бит).
- value — константа (20 бит).

### READ

- base_register — регистр базового адреса (7 бит).
- target_register — регистр назначения (7 бит).
- offset — смещение (11 бит).

### WRITE

- register — номер регистра (7 бит).
- address — адрес памяти (29 бит).

### ADD

- address_register — регистр адреса операнда (7 бит).
- target_register — регистр второго операнда и результата (7 бит).

Все операнды задаются целыми неотрицательными числами
в пределах выделенного количества бит.

## Аргументы командной строки

| Аргумент | Назначение |
|---|---|
| --input | Путь к исходному JSON-файлу |
| --output | Путь к выходному бинарному файлу |
| --test-mode | Включение тестового режима |

Ассемблер сохраняет машинный код в выходной бинарный файл
и выводит количество ассемблированных команд.
В тестовом режиме дополнительно выводятся байты каждой команды
в шестнадцатеричном формате.

## Описание функций

### assembler.py

- parse_args() — обработка аргументов командной строки.
- read_program() — чтение исходной программы из JSON.
- validate_operand() — проверка типа и диапазона операнда.
- translate_instruction() — преобразование отдельной команды.
- translate_program() — преобразование всей программы.
- print_test_result() — вывод машинного кода в HEX-формате.
- write_binary() — запись машинного кода в бинарный файл.
- main() — управление работой ассемблера и обработка ошибок.

### instructions.py

Содержит спецификацию команд УВМ, коды операций
и размеры битовых полей операндов.

### codec.py

- get_specification() — получение спецификации по коду операции.
- encode_instruction() — преобразование отдельной команды
  в машинный код с помощью побитовых операций.
- encode_program() — объединение машинного кода всех команд
  в единую последовательность байтов.
- decode_instruction() — декодирование машинной команды
  и восстановление значений её полей.

Каждая команда занимает 6 байт.
Для хранения машинного кода используется порядок
байтов Little-endian.

### memory.py

Класс Memory реализует объединённую память УВМ.

- __init__() — инициализация памяти.
- validate_address() — проверка допустимости адреса.
- read() — чтение значения из памяти.
- write() — запись значения в память.
- load_program() — загрузка машинного кода в память.
- dump_memory() — сохранение диапазона памяти в CSV.

### interpreter.py

Класс Interpreter реализует виртуальный процессор.

- __init__() — инициализация виртуальной машины.
- load_program() — загрузка программы и сброс состояния.
- fetch_instruction() — получение и декодирование команды.
- execute_instruction() — выбор и выполнение операции.
- execute_load_const() — загрузка константы в регистр.
- execute_read() — чтение значения из памяти в регистр.
- execute_write() — запись значения регистра в память.
- execute_add() — сложение значения регистра со значением
  из памяти и сохранение результата в регистр.
- run() — основной цикл выполнения программы.

Дополнительные функции:

- parse_args() — обработка аргументов командной строки.
- main() — управление работой интерпретатора.

Интерпретатор поддерживает выполнение всех четырёх
команд спецификации УВМ: LOAD_CONST, READ, WRITE и ADD.

## Запуск программы

Для работы необходим Python. Внешние зависимости
для запуска программы не требуются.
Отдельная сборка проекта не требуется.

```bash
python -m src.assembler --input examples/specification.json --output program.bin --test-mode
```

Запуск через скрипт Windows:

```bat
run.bat --input examples/specification.json --output program.bin --test-mode
```

## Пример копирования массива

Тестовая программа examples/copy_array.json копирует
массив [15, 25, 35] из ячеек памяти 100–102
в ячейки 200–202.

Ассемблирование программы:

```bash
python -m src.assembler --input examples/copy_array.json --output copy.bin
```

Выполнение программы:

```bash
python -m src.interpreter --input copy.bin --output dump.csv --range 200 202
```

Запуск через скрипт Windows:

```bat
run-interpreter.bat --input copy.bin --output dump.csv --range 200 202
```

Результат выполнения (dump.csv):

```csv
address,value
200,15
201,25
202,35
```

## Тестирование

Для автоматического тестирования используется
стандартная библиотека unittest.

Дополнительно тестируется формирование машинного кода
всех четырёх команд, последовательность байтов программы,
размер бинарного представления и обработка пустой программы.

Всего реализовано 41 автоматических тестов.

| Файл | Количество тестов |
|---|------------------:|
| test_assembler.py |                 7 |
| test_codec.py |                13 |
| test_memory.py |                 8 |
| test_interpreter.py |                13 |

Проверяется преобразование исходной программы,
кодирование и декодирование машинных команд,
работа памяти, регистров и интерпретатора.

Интеграционный тест проверяет совместную работу
ассемблера и интерпретатора на примере копирования массива.

Дополнительно проверяется выполнение арифметической
операции ADD, сложение с нулём и использование одного
регистра для адреса операнда и результата.
